# OctoAcme Project Management Docs

## Overview

OctoAcme uses a lightweight, iterative project management approach focused on customer value, cross-functional collaboration, and actionable documentation. Our methodology emphasizes:

- **Customer-first thinking**: Prioritize customer value and usability in every decision
- **Iterative delivery**: Deliver small, testable increments frequently
- **Clear ownership**: Each project has named owners with explicit responsibilities
- **Measurable goals**: Data-informed decisions and evidence-based iteration
- **Transparent risk management**: Proactive identification and communication of risks
- **Psychological safety**: Foster feedback, learning, and team accountability

Project work is structured into defined lifecycle stages: **Initiation**, **Planning**, **Execution**, **Release**, and **Retrospective**. Each stage is supported by explicit roles, checklists, and key artifacts to ensure consistent delivery and continuous improvement.
